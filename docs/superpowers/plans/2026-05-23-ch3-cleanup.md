### Task 3: Fix Table 3.6 formatting (Structural pattern categories)

**Files:**
- Modify: `docs/thesis/v2/chapters/c3_method.tex:444-459`

The table at line 449 uses `p{3.2cm}` for Pattern Category which causes justified text with ugly gaps.

- [ ] **Step 1: Add raggedright to the Pattern Category column and adjust widths**

Change:
```latex
\begin{tabular}{p{3.2cm}p{4.0cm}p{5.5cm}}
```
to:
```latex
\begin{tabular}{>{\raggedright\arraybackslash}p{3.2cm} >{\raggedright\arraybackslash}p{4.0cm} >{\raggedright\arraybackslash}p{5.5cm}}
```

This prevents justified text in all three columns, eliminating the inter-word gaps.
