### Task 5: Fix Table 4.3 column alignment

**Files:**
- Modify: `docs/thesis/v2/chapters/c4_experiments.tex:140-152`

- [ ] **Step 1: Center the number cells in DBMS-Nautilus and EBNF-Baseline columns**

The current table uses `@{}l@{\hspace{8pt}}l@{\hspace{8pt}}l@{\hspace{8pt}}r@{\hspace{8pt}}r@{}` — the last two columns (`r`) right-align the numbers. Change them to `c` (center) for the data rows only.

Replace the tabular spec:
```latex
\begin{tabular}{@{}l@{\hspace{8pt}}l@{\hspace{8pt}}l@{\hspace{8pt}}r@{\hspace{8pt}}r@{}}
```
with:
```latex
\begin{tabular}{@{}l@{\hspace{8pt}}l@{\hspace{8pt}}l@{\hspace{8pt}}c@{\hspace{8pt}}c@{}}
```

This centers "14/15", "5/5", "4/5*", "0/15", "0/5", "4/5", "0/5" and the "4/4", "1/4" totals in their columns while keeping the header text left-aligned (headers will also center but that's fine for short headers like "DBMS-Nautilus").
